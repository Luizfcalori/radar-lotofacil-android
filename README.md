# Radar da Lotofácil para Android

Projeto Android simples (WebView) que abre https://radar-lotofacil.vercel.app/.

## Gerar APK grátis
1. Abra a aba **Actions**.
2. Execute **Build APK - Radar da Lotofácil** com **Run workflow** (ou aguarde o build automático deste primeiro envio).
3. Na execução concluída, baixe o artefato `radar-lotofacil-apk`.
4. Extraia o ZIP e instale `app-debug.apk` no Android.

Este APK é um build debug para instalação direta e precisa de internet. Não é um pacote de publicação na Play Store.
